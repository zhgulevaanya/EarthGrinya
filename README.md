# EarthGrinya 

Учебное приложение на **C++/CLI (Windows Forms)** для моделирования задачи **спутникового позиционирования**: по измеренным амплитудам сигналов от группы спутников восстанавливаются трёхмерные координаты наземного источника, а также исследуется устойчивость решения к ошибкам в координатах спутников.

## Возможности

- **Интерактивная карта Земли** с координатной сеткой (широта/долгота, шаг 10°)
- **Выбор источника** — клик по карте задаёт точку на поверхности Земли, её 3D-координаты пересчитываются и отображаются
- **Ручная расстановка спутников** — клик по карте ставит спутник на орбиту (700 км над поверхностью); можно расставить заданное число `N ≥ 4`
- **Автоматическая генерация спутников** — случайное равномерное распределение по орбитальной сфере
- **Зашумление координат спутников** — ползунок `Delta` задаёт процент искажения орбитальных координат (0–20%)
- **Поиск координат источника** методом **Хука–Дживса** (прямой поиск с исследующим поиском и ускоряющим шагом) по критерию минимума невязки относительных амплитуд
- **Таблица спутников** (DataGridView): координаты X/Y/Z и измеренная амплитуда
- **График зависимости СКО** ошибки координат источника от процента искажения координат спутников (усреднение по нескольким случайным конфигурациям)
- Вывод найденных координат и их отклонений от истинных

## Технические детали

- **Модель сигнала:** `A = C / d`, где `d` — расстояние от спутника до источника
- **Целевая функция:** сумма квадратов невязок относительных амплитуд + штраф за отклонение от поверхности Земли
- **Оптимизация:** метод Хука–Дживса с адаптивным шагом, старт с точки на поверхности Земли
- Радиус Земли ≈ 6 371 000 м, орбита ≈ 7 071 000 м
- Всё рисование на карте — GDI+ поверх исходного изображения (`Bitmap`), исходник сохраняется отдельно

## Сборка

Требуется Visual Studio с поддержкой **C++/CLI** (`.NET Framework`).

## Сценарий работы

1. **Выбрать расположение приёмника** → клик по карте → координаты источника заполняются
2. Задать количество спутников `N ≥ 4` и процент искажения `Delta`
3. *(опционально)* **Выбрать расположение спутников** → `N` кликов по карте
4. **Рассчитать** → выполняется поиск координат, заполняется таблица, строятся графики ошибок
